# 项目定位与面试材料入口

项目定位为可嵌入业务网页的可信数据分析 Copilot：复用 Vanna 的 Agent、工具和 Web Component，
重点建设业务语义、连续分析状态、受控 SQL 执行、可信结果与可部署性。当前在线默认模型为
SiliconFlow `deepseek-ai/DeepSeek-V3.2`，本地 Adapter 仍是离线研究资产。

贡献、可使用的简历表述、实际评测分母及不能声称的能力统一维护在
[面试项目事实](interview/project-release-facts-v1.md)，不再在此维护第二份数字清单。
当前已有本地账号与来源绑定嵌入令牌，但没有企业 SSO、组织行权限或外部企业使用记录。
学习继续按[四周计划](../plan/process-agent-internship-improvement-v1.md)，以亲自看代码和复述为准。
