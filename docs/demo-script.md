# 面试演示脚本

本脚本用于展示已验证的能力，而不是现场承诺模型一定生成某条 SQL。演示前确认可信服务运行在
`127.0.0.1:32010`，并打开 `/embedded-demo`。

## 1. 先说明边界

说明这是 Olist 巴西公开电商数据的可信 Text-to-SQL Demo。分析窗口可嵌入已有经营页面；查询只读，
结果应附带版本、表格和 SQL 证据。不要称它为中国真实业务数据或生产登录系统。

## 2. 展示嵌入体验

打开右下角“经营分析副驾”，拖动和缩放窗口，再最大化和恢复。移动端场景只展示自适应布局，不演示桌面拖拽。

## 3. 执行固定场景

依次点击“州前五”“品类前十”“指标概览”。观察问题、流式状态、结果表、SQL、审计摘要和数据/指标版本。

州前五应产生柱状图，且图表仅使用本次查询结果；品类前十与指标概览不要求图表。预期行、排序和指标口径见
`evals/cases/demo_scenarios.yaml`，如结果偏离该契约，应停止演示并检查模型生成 SQL 或数据版本。

## 4. 展示权限边界

在宿主页角色控件中切换分析员和管理员。说明它是签名的演示会话而不是真实认证。可展示：分析员 LIMIT 为 200、
不能访问 `dataset_versions` 或投影敏感标识；管理员 LIMIT 为 1000，并可查看全部审计。不要声称已实现组织级行权限。

## 5. 展示安全与可复现性

说明所有模型 SQL 都先经 `sqlglot` AST 策略再由 PostgreSQL 只读角色执行，审计由独立应用写角色记录。
展示 `python scripts/run_demo_scenario_evaluation.py --database --output /tmp/demo.yaml` 返回成功，强调这验证的是数据与 SQL 语义，不是 LLM 准确率。
