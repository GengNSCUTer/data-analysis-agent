# W4-04 演示脚本

这是 5–8 分钟的当前产品演示，也是全量功能测试的步骤说明。自动执行入口是 [`evals/cases/w4_04_product_demo_v1.yaml`](../evals/cases/w4_04_product_demo_v1.yaml) 和 `tests/test_w4_04_product_demo.py`。页面是 `http://127.0.0.1:32013/embedded-copilot`。

默认测试检查登录边界、路由、澄清、结果追问、黄金结果合同和页面控件。设置 `RUN_VANNA_LIVE=1` 后，同一脚本会向正在运行的 `127.0.0.1:32013` 发送真实对话：拒绝和澄清不得查库，州前五的返回行必须等于黄金合同，结果追问不得再查库，并下载该结果文件。

## 0. 登录

打开页面。未登录时只看到登录卡。使用本地账号 `analyst`，密码在仓库外的 `local-auth/bootstrap-password.txt`。登录后进入工作区 `olist-demo`。

说明这是本地账号，不是外部身份提供商。浏览器不能自己声明用户或角色。

## 1. 查看依据

打开顶栏「更多」，再点「查看依据」。只应看到数据版本、指标版本和只读执行边界。不要在主画面展示 SQL 或全局审计。

## 2. 安全拒绝

输入「删除订单」。系统拒绝写库，不生成 SQL。

## 3. 澄清

输入「本月 GMV 是多少」。系统要求给出明确日期，不把「本月」当成日历时间。

## 4. 表和图

输入「按客户州统计有效订单数前五名，并生成柱状图」。演示时看结果表和柱状图。自动测试核对黄金合同：SP 41127、RJ 12698、MG 11496、RS 5417、PR 4983，有效订单排除 canceled 和 unavailable。

## 5. 结果追问

在已有可信结果之后输入「这个结果是否合理」。这一问解释上一轮结果，不为此再查库。

## 6. 保存、下载和偏好

「保存本次分析」只保留已校验结果的版本，不进入下一问。「下载完整结果」下载的是该结果文件，不是界面上的 200 行预览。左侧偏好目前只保存供回看，尚未实际改变展示或 SQL。

## 7. 管理里的跨域令牌

在「更多」里打开「管理」。演示角色和审计默认不可见。本地登录后，演示角色切换不覆盖当前账号。可以为允许列表中的 origin 签发 5 分钟嵌入令牌；来源不匹配的令牌无效。

## 不在这 8 分钟里承诺的事

TheLook 不在这个页面。本地小模型不是默认回答模型。DPO 没有启动。Phase B 的人工语义审核还没填。
