# 业务结果与解释收尾实现

本轮针对2026-11-11完整验收的七项失败，以及此前用户金额冒充州总额的真实反例。
不改变原60题、SQL安全权限、数值容差、训练或记忆架构。

查询生成前，语义解释器在原有最多两次调用内试应用状态补丁；仅结构错误可纠正，
Catalog/权限拒绝不改成可重试。运行时仍负责真正应用状态及解析排名实体引用。

查询执行前，PlanSqlGuard拒绝把输出指标本身用作最终分组键的已知错误形式；仍保留
已有金额来源、公式和JOIN检查。执行后ResultValidator依据QueryPlan完整维度加时间键
检查唯一性；无维度的标量至多一行，多维/时间结果允许同一州跨品类或月份重复。
这不是任意SQL公式的等价证明，仍需独立SQL数值对照。

解释保持模型自由写正文，检查结果分别记录确定错误、语义疑点和缺少证据。
完整两行结果提前计算唯一一对比较，避免正确差额在修订时才申请取证；模型也可提出一次
受控补算，补证与修改错误分开计数。最多四次模型请求、一次修订、一次显式补算；共享
90秒解释截止时间，复核最多20秒、补证后写作及修订最多30秒。任何阶段不授SQL工具权限。

明确ISO日期区间对照实际半开范围；公式阈值按已引用Catalog定义送复核，不混成观测金额，
也不豁免真正的错误百分数。Catalog可加维度一并进入证据与复核，区分Top-N子集与全分组。
数字仍绑定具体实体/指标/引用；其他行出现0%不能证明Ceuta也是0%。

失败诊断仅在owner限定的Run审计保存有限失败段落和引用，不发送未经核验正文，不写入
正常聊天回答。语义复核仍可能漏检，accepted不能替代业务审阅与独立参考。

双历史来源按[历史复用说明](historical-artifact-reuse-v2.md)显式比较；不自动JOIN或改任务。
最终验收成绩由单次完整60项报告记录，不拼接定向重测成绩。
