# 执行行数上限 v1

对外最多返回 1,000 行。界面预览仍是 200 行，这两件事分开说。

策略自己补上或收紧到 1,000 行时，执行会多读 1 行，只用来判断后面还有没有数据。这一行不进入结果表、摘要、图表、下载文件或模型上下文，也不写入审计里的结果行。

- 多读到了那一行：告诉用户结果超过 1,000 行，只返回前 1,000 行。
- 没有多读到：即使正好 1,000 行，也视为这次查询完整返回，不再说成“可能被截断”。
- 模型自己写了更小的 `LIMIT`：按那个上限返回，不把满限当成执行截断。

没有这条判断之前，校验把“行数达到 1,000”一律当成截断。那个默认只留给没有做多读判断的调用方。
