# 文档生命周期地图 v1

**状态：** 当前文档治理入口（2026-11-12更新）。

本项目同时包含产品运行时、数据合同、后训练实验和学习材料。它们的证据等级和读者不同，不能通过把所有内容合并成一篇长文档来解决混乱。本地图规定每类内容的唯一当前入口、历史保留方式和更新规则。

## 归档与删除规则

历史实验报告、数据来源、模型结果和失败证据具有不可替代的溯源价值，即使不再是当前结论也保留原文，并在文件头标注“历史/被替代”。不通过文件名猜测过时，不批量删除 `verification-*`、`post-training-*` 或日期报告。

7个仅跳转的根目录后训练入口及重复简历草稿已删除，引用直接改到规范正文，不维护兼容页。
有独有内容的根目录实验报告仍保留。删除前确认内容已迁移、证据无唯一性、调用方及文档
链接已更新，并检查受影响链接。物理整理不混入新功能开发。

## 当前状态标记

- `Current`：当前规范或当前事实入口。
- `Proposed`：设计已讨论但尚未实现，不能当作产品能力。
- `Complete`：代码和定向测试已完成；仍须区分测试覆盖范围和未验证能力。
- `Historical`：保留证据，不用于当前配置、训练或评测结论。

文档审阅时先看状态和证据路径，再看正文。若当前文档与旧报告冲突，以最新版本合同、测试和 `PROJECT.md` 的追加事实为准。
