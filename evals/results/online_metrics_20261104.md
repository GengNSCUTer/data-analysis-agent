renderer或重写历史实验Catalog。指标定义见[在线指标说明](../../docs/workspaces/online-metrics-v1.md)。

## 实现

新在线Catalog与原实验Catalog分开，由现有workspace配置选择。数据表/权限未扩张；Olist
增加显式维度绑定。全部订单数允许空默认过滤，避免被套用“有效订单”过滤；支付金额约束
支付事实来源，库存成本约束库存单元cost来源。运费比例及两库复购率不进入可加指标列表；
全部订单数按品类/支付方式分组时保留multi-membership不可加约束。

库存数/成本统一通过Catalog的`temporal_mode=current_snapshot`表达无历史快照能力，由
QueryPlan在SQL生成前处理不支持的历史日期/趋势。语义解释器读取同一能力。期间复购按所选
时间桶/分组内订单数先聚合到客户，再算客户比例；不使用Olist每单变化的customer_id代表人。

指标定义随可信数值进入解释及复核证据，并在工件恢复后重新从当前Catalog取定义。公式中
阈值与观测值区别引用；带定义但同时引用错误业务数值的负例仍拒绝。保留一次修订和失败回退，
没有为了通过测试直接放行解释。正常正文仍由模型撰写，不改成服务端业务句式。

## 验收发现并处理的问题

| 发现 | 修复与证据 |
| --- | --- |
| TheLook月度复购与参考SQL不一致 | 原连接继承本地时区，UTC月界附近订单归属不同。只读事务明确SET LOCAL TIME ZONE UTC；真实PG测试故意建立上海时区连接验证跨月边界，真实月度复购复测与独立SQL一致 |
| Olist月度复购被行数预算误拦 | 同时出现date和month时，虚拟时间维度被重复计数。规范为time_grain表达时间分组，保存状态与有效意图一致；全量意图和patch两条路径均测试 |
| 运费分组自行排除未分类 | 计划检查覆盖实际分组路径的显式IS NOT NULL，原候选与一次修复共用；保留指标列非空规则、已确认维度筛选、OR条件和未使用CTE正例。真实原错误SQL回放已拒绝；修复后74组均保留 |
| CSV把缺失分组写成字符串nan | 缺失标量统一写空值，真实字符串nan/null、0及普通值保持原义；下载/重读和真实NULL品类数值对照通过 |
| 多层支付预聚合触发JOIN诊断超时拒绝 | 原合法复杂CTE确实被5秒共享预算拒绝，未放宽安全措施或延长预算。支付指标指导直接关联唯一订单/客户后SUM，定向五轮链通过；不声称所有等价复杂CTE都已支持 |
| 缺失标签、品类译名和安全状态被评测误判 | 验收只按显式缺失标签及数据库翻译表做独立映射，不改金额/比例、不丢分组；错误数值/缺组负例仍失败。unauthorized作为敏感请求的正确拒绝状态 |
| 新文件只在当前开发机存在的打包风险 | 更新ProductBuild和MANIFEST，新增空目录资产构建验证；合成Olist初始化使用在线Catalog。原实验Catalog不修改 |

初期一条题要求“不翻译葡语”却得到英文，属于原指令遵循偏差，不把该次结果改判为通过。
最终业务题允许Catalog定义的品类名称，用独立翻译表验证等价标签；原始问题/SQL保留。
环形图原本最多8类。初期请求全部10个配送中心时按既有合同拒绝绘图；最终明确取前5，
未扩大图表类别上限，也没有把前5构成说成全业务构成。

## 保留的文字解释边界

三轮仍发生一次修订后不通过：Olist月度复购、TheLook取消率、TheLook月度复购。记录中有
numeric_mismatch、invalid_reference等；表格/CSV与独立SQL一致，未将未经核验正文发给用户。
不将这些回退全部归因为检查器误判，也不声称新指标上线已经解决所有自由文本解释问题。
这次没有为得到更好分数重复采样这三轮或放宽事实校验。

关联诊断和金额来源检查仍有覆盖边界；不能证明任意比例公式、遗漏状态过滤或任意SQL都
业务正确。复杂多层预聚合也可能受诊断能力/共享执行预算限制。当前数据库是公开快照，
库存成本不能当实时财务估值，复购率不等于终身留存，测试未覆盖生产并发SLA。
