# 产品开发用例质量复核：2026-10-19

本轮对应[产品完善计划第二项](../../plan/process-agent-product-readiness-v1.md#implementation-phase-2)。
60 个独立开发场景通过当前 Olist 产品的登录、SSE、在线模型、PostgreSQL 和工件路径运行，
共 73 轮。它们不是训练数据或 protected final test；本轮没有训练或选择本地 Adapter。

**结论：业务质量审查已完成，产品仍有明确缺口。** 使用统一修正后的判定标准，原始全量运行
为 45/60；将受影响场景的定向复测替换进去后为 **51/60**。该数字是行为要求加选定数值检查的
通过数，不是全量语义准确率，也不是修复后重新完整运行 60 题的成绩。最终证据来自原始 r2 的
62 轮、r3 的 9 轮和 r4 的 2 轮。

## 本轮修复的三类问题

**结果可用性与展示。** `SUM` 无匹配记录时可能返回一行 NULL，并不等于数据库执行失败。
`ResultValidator` 现在将全空指标标为 degraded：可以解释无可用值，不能产生可信数字摘要，
不由服务端把 NULL 改成 0。完整品类输出还需要保留 73 个非空品类之外的一个 NULL 分组，
因此在线预算改为 74；历史离线的 73 行协议不改。图表允许把分类 NULL 标为“（空值）”，只改
绘图副本的标签，不修改 CSV、删组、合计或补指标；指标/时间空值与重复键仍拒绝。

**指标单位与精度。** Catalog 提示现在明确比例输出 0–1，小数比例不乘 100。独立核对另发现
某次履约天数使用 `EXTRACT(DAY)` 截去不足一天的时间，州均值偏低约 0.4–0.5 天；在线 v3
Catalog 的现有定义补充为按总秒数 / 86400.0 计算后求平均。没有改动原指标的业务含义或历史
离线数据。月度好评率与州履约天数的定向复测均与独立参考一致。

**最小澄清。** 语义解释提示区分“新分析缺指标”和“追问继承已确认指标”，没有增加关键词闸门
或额外模型调用。一条无指标问题恢复澄清；另一条仍擅自选择 GMV，所以本项只是部分改善。

## 判定器修正与证据边界

原运行器先报 38/60，其中包含判定器和预期错误，不能作为修复前准确率。复核保留原问题，
只纠正不符合当前实际能力的判定：指标顺序不代表集合错误；年度分组不要求额外的自由文本
baseline；“最近”可使用当前最近 30 天默认；支付方式 GMV 已有 payment-share 规则；没有
时间限定的月度趋势可使用全量时间；只换图属于结果复用；读服务器文件属于越权拒绝。
无上文时的下载可以解释无结果，不要求走唯一一种澄清状态。

同时收紧两个原先误判通过的场景：“不存在的月份”没有给定具体月份，应澄清，不能算空窗口
验证；半年度对比加入两窗口独立数值对照，不能只检查存在时间范围。因果追问可以识别 GMV，
不应因其识别出指标而判错，但仍不能直接给没有证据的因果结论。

过滤、实体引用和只换图复用现在检查实际 filter dimension / validated artifact reuse；不再只
检查路由。最终报告保留每轮来源和差异，不使用改变题目、删除失败或反复采样取最好结果计分。

## 回归、浏览器与时延

相关 Python/数据库回归 **231 passed、5 skipped**；跳过的是需显式开启 E2E 环境的 SSE 资产
测试，不计成功。定向 Ruff 通过。现有产品壳/预览/移动端/澄清浏览器回归 **7 passed**。
真实浏览器 + 模型 + PostgreSQL 的三轮州→品类→Top 10 通过，末轮数值和排名由独立 SQL 核对。
新增品类柱状图和履约天数柱状图也分别通过独立数值核对；品类保留完整 74 行及空值标签。

早期浏览器核对曾把 CSV 分页返回的空字符串与 SQL NULL 直接比较，导致测试误报；改成读取
同一已授权 CSV 下载，按 CSV 规则解析，保留早期失败证据。空状态浏览器还出现过一次
`query_timeout`；另一次模型主动使用 COALESCE 得到 0，不能当作 NULL 展示路径的验证。
因此额外使用明确要求保留空值的请求验证该分支，**1 项通过**，无可信数字工件，界面显示
无可用指标值。最终真实浏览器定向验收共 **4 组、6 轮通过**：三轮下钻，以及品类图、履约图、
明确空值请求各一轮；它们不是一次全量重跑的结果。早期失败证据全部保留。

原始全量 73 轮服务端耗时 P50 **22.8 秒**、P95 **48.2 秒**；混合证据 P50 **22.8 秒**、
P95 **59.0 秒**。小样本和模型服务波动不能支持提速结论或 SLA。浏览器三轮复验耗时
137.77 秒，仍存在明显的模型生成与重试延迟；请求并发和故障处理留给既定第五项。
